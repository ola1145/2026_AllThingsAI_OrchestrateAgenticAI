## 2026-03-02 - [Reveal.js Iframe Focus-Visible State & Custom Elements]
**Learning:** Interactive explainer pages embedded via iframe in Reveal.js slides do not inherit focus outline settings, and default browser focus indicators are frequently invisible against dark backgrounds. Custom interactive card components constructed out of `div` tags with `onclick` are completely unreachable via keyboard navigation unless explicitly mapped to the keyboard tab order and equipped with explicit `:focus-visible` styles.
**Action:** Always add custom `:focus-visible` outline rules with clear offsets (e.g., matching the theme primary color) to interactive triggers in iframe-embedded assets. Map div-based clickable components using `tabindex="0"`, `role="button"`, `aria-expanded`, and native `keydown` keyhandlers.
