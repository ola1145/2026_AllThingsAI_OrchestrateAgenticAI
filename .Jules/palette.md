## 2026-08-07 - Focus Cascade Failure in Embedded Presentation Iframes
**Learning:** Interactive explainers embedded as `iframe` blocks within presentation frameworks like Reveal.js operate in fully isolated DOM boundaries. Global CSS themes and focus indicators on the host slide deck do not cascade into the iframe. Consequently, native focus indicators are often invisible or lost on elements like summaries, navigation links, buttons, and custom interactive div components unless explicitly styled inside the embedded explainer document's CSS.
**Action:** When designing embedded widgets or iframe-based explainers, always explicitly define custom CSS focus styles using `:focus-visible` to match the localized theme. Additionally, ensure custom interactive elements have native keyboard navigable capabilities (`tabindex="0"`, `role="button"`, `aria-expanded`, and keyboard handlers for Space and Enter).
