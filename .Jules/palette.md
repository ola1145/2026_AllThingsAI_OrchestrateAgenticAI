## 2026-09-20 - Focus Indicators in Embedded HTML Explainers
**Learning:** Standalone HTML explainers embedded in slides require explicit `:focus-visible` outline styles on interactive elements like TOC links (`.toc a`) and collapsible summaries (`details.collapsible summary`) to provide clear visual feedback during keyboard navigation (`Tab`).
**Action:** Always verify `:focus-visible` states on custom navigation and details/summary elements when designing interactive HTML components.
